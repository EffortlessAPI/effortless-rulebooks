ERB-PKO Enterprise Extension 1.0.0

Explicit extension for elicitation, tacit knowledge, governance, learning, operational bindings, and communication-channel policy.

This document defines the 203 terms used by the Procedural Knowledge Ontology register that PKO 2.0.0 does not define. Terms PKO does define are used directly under their own IRIs and are not repeated here. The distinction between a native term, a reused external term and an extension is recorded as data in the register's SemanticMappings table, and this page is generated from it.
