Effortless Rulebooks

Documents published from the rulebooks in EffortlessAPI/effortless-rulebooks. Every page here is generated from a rulebook's own database views; none of it is written by hand.

ERB-PKO Enterprise Extension vocabulary

The terms the Procedural Knowledge Ontology register uses that PKO 2.0.0 does not define, each with a resolvable IRI. This is what https://effortlessapi.github.io/effortless-rulebooks/ns/pko-extension# dereferences to, served as HTML carrying its own JSON-LD, with Turtle and JSON-LD alternates.

Procedural Knowledge Ontology — the register, by role

One page per role, showing what that person can see and change, and the measures that describe their part of the model. Read from the same vw_* views the application reads.
