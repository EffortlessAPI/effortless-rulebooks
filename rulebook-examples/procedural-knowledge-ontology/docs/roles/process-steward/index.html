Which steps can a procedure send work back to after they have already run — which steps sit on a rework loop, and which of those carry a blocking control that must hold on every pass?

Every witness we have looks at one transition at a time (IsUnwalkedRecoveryPath asks whether that one edge was ever traversed). None of them can say that a step is re-entered, because loop membership is reachability over paths of any length. That is transitive closure, which no formula expresses, so it needs the substrate-native closure over StepTransitions.
