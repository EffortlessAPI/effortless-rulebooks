How this site is built

The rulebook is the single source of truth. effortless build compiles it into a Postgres schema in which every rulebook formula becomes a column of a generated vw_* view — 259 entity views in this model. This site reads those views and nothing else: no value on any page was computed by the site generator, and no value was read from the rulebook JSON. Each metric carries the view.column it came from, so any number here can be checked with one SELECT.
