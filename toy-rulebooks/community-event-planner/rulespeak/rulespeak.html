ƒ Event Status Calculated 4 hops from ground truth string DR-16
In RuleSpeak®

The event's event status is determined by the following priority:

  1. “ready” if all of these hold:
    • the speakers flag is set
    • the at capacity flag is not set
    • the venue conflict flag is not set
  2. “issues” in all other cases
In plain words

If has speakers, not at capacity, and not has venue conflict then "ready", otherwise "issues".

As a formula
= IF(AND(Has Speakers, NOT(At Capacity), NOT(Has Venue Conflict)), "ready", "issues")
