ƒ 边的类型 Calculated string DR-1
In RuleSpeak®

A 形状's 边的类型 is computed as the value matched against the 边的数量: “空” when it is 0; “点” when it is 1; “线” when it is 2; “三角形” when it is 3; “正方形” when it is 4; otherwise “--”.

In plain words

Switch(边的数量, 0, "空", 1, "点", 2, "线", 3, "三角形", 4, "正方形", "--").

As a formula
= SWITCH({{边的数量}}, 0, "空", 1, "点", 2, "线", 3, "三角形", 4, "正方形", "--" )

ƒ 勾股定理成立 Calculated string DR-9
In RuleSpeak®

The 形状's 勾股定理成立 is determined by the following priority:

  1. the 非斜边角度总和 is the 最大边长 times the 最大边长 if the 边的数量 is 3
  2. no value in all other cases
In plain words

If 边的数量 equals 3 then 非斜边角度总和 equals (最大边长 times 最大边长), otherwise blank().

As a formula
= IF({{边的数量}} = 3, {{非斜边角度总和}} = {{最大边长}} * {{最大边长}}, BLANK() )
